Research Framework

Strategic Cognitive Offloading Framework

This three-level framework organizes the entire research program around a central question: how should cognitive effort be optimally distributed between human learners and AI? It bridges theoretical grounding, empirical mechanisms, and data-driven validation into a single coherent architecture.

Level 1 — Theoretical Foundation

Grounded in Strategic Cognitive Offloading theory, this level asks how cognitive load, metacognition, and human–AI collaboration interact. The core distinction: offloading that frees working memory for deeper reasoning versus offloading that short-circuits thinking altogether.

Level 2 — AI-Mediated Learning Mechanisms

Identifies the causal chain from AI–learner dialogue → argumentation & scaffolding → cognitive transfer → higher-order thinking. Each mechanism is empirically examined across argumentation, creativity, geometry, and language learning contexts.

Level 3 — Data-Driven Evidence

Interaction data modeled through log data, Sequential Pattern Mining (SPM), GNN interaction modeling, and learning analytics — producing mechanism identification, predictive models, and model validation.
